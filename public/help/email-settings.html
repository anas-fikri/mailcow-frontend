📧 Panduan Setting Email

Konfigurasi aplikasi email (Outlook, Apple Mail, Thunderbird) untuk akun korporat PCP Express — lengkap dengan port alternatif bila port standar diblokir ISP.

1. Pengaturan Server

ParameterNilai
Webmailwebmail
Server email (IMAP/SMTP)mail.pcpexpress.com
Nama pengguna (username)Alamat email lengkap, contoh: nama@pcpexpress.com
AutentikasiPassword biasa (password webmail), tanpa OAuth
KeamananSelalu SSL/TLS — jangan pernah nonaktifkan verifikasi sertifikat

Host menyesuaikan domain akun Anda (mail.<domain>).

2. Pilih Port yang Benar

FungsiStandar Kantor / jaringan internalAlternatif Dari luar / ISP memblokir
IMAP (terima email)993 SSL/TLS1993 SSL/TLS
POP3 (opsional)995 SSL/TLS—
SMTP (kirim email)465 SSL/TLS1465 SSL/TLS
SMTP (kirim, alternatif STARTTLS)587 STARTTLS1587 STARTTLS

✔ Terverifikasi: port standar terbuka di jaringan internal; dari internet port 1993/1465/1587 yang aktif (993/465/587 diblokir sebagian ISP). Jika satu set gagal, coba set lainnya — keduanya SSL/TLS yang sama amannya.

3. Outlook — Windows

  1. Buka Outlook → File → Tambah Akun → masukkan alamat email → Lanjut.
  2. Jika gagal otomatis: pilih Pengaturan Lanjutan → Biarkan saya menyiapkan akun secara manual.
  3. Jenis akun: IMAP.
  4. Isi:
    FieldNilai
    Server masuk (IMAP)mail.pcpexpress.com — port 993 (atau 1993)
    Metode enkripsi masukSSL/TLS
    Server keluar (SMTP)mail.pcpexpress.com — port 465 (atau 1465)
    Metode enkripsi keluarSSL/TLS
  5. Klik Tambah Akun → masukkan password webmail → selesai.

4. Outlook — macOS

  1. Buka Outlook → menu Outlook → Pengaturan → Akun → + → Tambah Akun.
  2. Masukkan email → jika gagal otomatis, pilih Konfigurasi Manual.
  3. Jenis: IMAP; isi server masuk mail.pcpexpress.com port 993 (atau 1993), server keluar port 465 (atau 1465), keduanya SSL/TLS.
  4. Username = email lengkap, password = password webmail → Tambahkan Akun.

5. Apple Mail — iPhone / iPad / Mac

  1. iPhone/iPad: Pengaturan → Mail → Akun → Tambah Akun → Lainnya → Tambah Akun Mail.
  2. Mac: Mail → Pengaturan → Akun → + → Akun Mail Lainnya.
  3. Isi:
    FieldNilai
    NamaNama Anda
    Email / Alamatnama@pcpexpress.com
    Server IMAP masukmail.pcpexpress.com — port 993 (atau 1993)
    Server SMTP keluarmail.pcpexpress.com — port 465 (atau 1465)
  4. Password = password webmail → Berikutnya → simpan.

6. Thunderbird (Windows / macOS / Linux)

  1. Buka Thunderbird → Tambah Akun Email → masukkan nama, email, password → Lanjut.
  2. Jika deteksi otomatis gagal: klik Konfigurasi Manual.
  3. Isi:
    SettingNilai
    Server masuk (IMAP)mail.pcpexpress.com — port 993, SSL/TLS
    Server keluar (SMTP)mail.pcpexpress.com — port 465, SSL/TLS
    AutentikasiPassword normal
  4. Jika port di atas gagal: ganti IMAP ke 1993 dan SMTP ke 1465 (atau SMTP 1587 STARTTLS).

7. Tips Keamanan

  • Selalu gunakan SSL/TLS; jangan pernah memilih "tanpa enkripsi" atau nonaktifkan verifikasi sertifikat.
  • Jangan berbagi password dengan siapa pun — admin tidak akan pernah memintanya.
  • Jika email terkirim gagal dengan "Mail delivery failed", periksa ejaan alamat tujuan.

Jika pengaturan di atas tidak berhasil, hubungi tim IT/DevOps PCP Express.
