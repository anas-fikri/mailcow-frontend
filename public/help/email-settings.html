📧 Panduan Setting Email

Konfigurasi aplikasi email (Outlook, Thunderbird, iPhone, Android, dll.) untuk akun korporat PCP Express.

Pengaturan Server

ParameterNilai
Webmailwebmail
Server email (IMAP/POP/SMTP)mail.pcpexpress.com
IMAP Port993 (SSL/TLS)
POP3 Port (opsional)995 (SSL/TLS)
SMTP Port465 (SSL/TLS) atau 587 (STARTTLS)
AutentikasiPassword biasa (password webmail), tanpa OAuth
Nama pengguna (username)Alamat email lengkap, contoh: nama@pcpexpress.com

Selalu gunakan SSL/TLS. Jangan pernah menonaktifkan verifikasi sertifikat.

Panduan Cepat

  • Outlook (Windows/macOS): Tambah akun → masukkan alamat email → pilih "saya akan mengonfigurasi secara manual" → isi IMAP 993 & SMTP 465 (SSL) dengan host di atas.
  • Thunderbird: Tambah akun → masukkan nama, email, password → jika deteksi otomatis gagal, pilih "Konfigurasi manual" dan isi IMAP/SMTP di atas.
  • iPhone/iPad (Mail): Pengaturan → Mail → Akun → Tambah Akun → Lainnya → Mail Baru → isi IMAP/SMTP manual.
  • Android (Gmail/Email): Tambah akun → Lainnya (IMAP) → isi server masuk mail.<domain> port 993, server keluar port 465.
  • Webmail: Cukup buka webmail dan login dengan alamat email + password.

Tips Keamanan

  • Jangan berbagi password dengan siapa pun. Admin tidak akan pernah meminta password Anda.
  • Hindari login di perangkat publik; selalu logout setelah selesai.
  • Jika email terkirim gagal dengan pesan "Mail delivery failed", periksa ejaan alamat tujuan.

Jika pengaturan di atas tidak berhasil, hubungi tim IT/DevOps PCP Express.
